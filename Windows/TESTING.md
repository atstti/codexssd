# Windows版 1.0.0 検証記録

[GitHub Actions実行結果](https://github.com/atstti/codexssd/actions/runs/42220752350)

Windowsランナー上で次を確認しました。

- 容量変換・0と取得失敗の区別・十進単位・オーバーフロー・比較情報の未丸め値の5件：成功。
- .NETを含むwin-x64自己完結型の配布EXEビルド：成功。
- **配布EXE自身**の `--smoke-test`：成功。実際の起動ドライブをGetDiskFreeSpaceExWで取得し、DriveInfoの総容量と比較。
- WinFormsウィンドウの生成・表示と容量一覧の構築：成功。
- 比較情報のクリップボードへの書き込みと読み戻し：成功。
- ZIP作成・再展開・EXE存在確認：成功。取得した配布ファイルはPE32+ GUI x86-64。

未確認：利用者のPCでの対話的な画面操作、通知領域の表示位置やマウス操作、外付けドライブ接続・取り外し、30秒更新の長時間運用、ディスククォータ環境、SmartScreen経由の起動、フォルダマウント専用ボリューム。

スモークテストはWindowsランナーによる自動操作です。実ユーザーが画面を見て操作した確認とは区別します。アプリは未署名です。
