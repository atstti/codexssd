# Windows版 1.2.3 検証記録

[GitHub Actions実行結果](https://github.com/atstti/codexssd/actions/runs/42235924643)

Windowsランナー上で次を確認しました。

- 容量変換・0と取得失敗の区別・1024進・小数第2位表示・オーバーフロー・比較情報の未丸め値、ゲージ比率など8件：成功。
- ユーザーの画像の空き394,110,242,816バイト→367.04 GB、総容量998,976,253,952バイト→930.37 GBを1024進・小数第2位で整形：成功。
- 1 GB未満ではMB等を用い、0と取得失敗を区別：成功。
- .NETを含むwin-x64自己完結型の配布EXEビルド：成功。
- **配布EXE自身**の `--smoke-test`：成功。実際の起動ドライブをGetDiskFreeSpaceExWで取得し、DriveInfoの総容量と比較。
- 詳細ウィンドウとフローティングパネルの生成・表示：成功。
- フローティングの枠なし・最前面プロパティ、格納・再表示、0容量・取得失敗の描画：成功。
- 拡大サイズと最小サイズでの全操作部品のウィンドウ内配置：成功。
- 横幅のみ・高さのみ・縦横同時の変更を合計240回実行し、毎回の再描画と各部品のFont.Height参照：成功。
- ユーザー環境の破棄済みフォント参照（ComboBoxの高さ計算）に対してフォントの寿命管理を修正。修正前の短いCIテストでは同じ例外は再現しなかったため、ユーザー環境での再確認が必要。
- 不透明度65%への変更、および別ウィンドウでのサイズ・不透明度の設定復元：成功。
- サンプル容量を使う描画プレビューを生成して見た目を確認。実ドライブのスモークテスト値とは区別。
- 比較情報のクリップボードへの書き込みと読み戻し：成功。
- ZIP作成・再展開・EXE存在確認：成功。取得した配布ファイルはPE32+ GUI x86-64。

未確認：利用者のPCでの対話的な画面操作、通知領域の表示位置やマウス操作、ドラッグ移動の実操作、高DPI・複数モニター環境での操作、外付けドライブ接続・取り外し、30秒更新の長時間運用、ディスククォータ環境、SmartScreen経由の起動、フォルダマウント専用ボリューム。

スモークテストはWindowsランナーによる自動操作です。実ユーザーが画面を見て操作した確認とは区別します。アプリは未署名です。
