DiskSpace Windows 1.2.3（Windows 10 / 11、x64）

使い方
1. 配布ZIPを「すべて展開」します。
2. DiskSpace.exeをダブルクリックします。.NETの追加インストールは不要です。
3. 起動するとネイビー色のフローティングパネルに、残容量と円形ゲージを表示します。
   上部のDISKSPACE付近をドラッグして移動できます。位置は次回起動時に復元します。
   「最前面 ON/OFF」で重なり順を変更できます。
   右下やウィンドウの縁をドラッグするとサイズを変更できます（文字・ゲージも拡大縮小）。
   下部の「不透明度」で40〜100%に調整できます。サイズと不透明度も次回起動時に復元します。
   ウィンドウ全体（文字やボタンも含む）が半透明になります。背景だけの透過ではありません。
   アイコンが見えない場合はタスクバーの「∧」を開いてください。
4. 上部のドライブ一覧で対象を切り替えます。「詳細・比較」で従来の容量一覧が開きます。
   パネルの「—」で通知領域へ格納し、アイコンをクリックすると再表示します。
5. 「コピー」で比較情報を取得できます。円形ゲージは保存に使える空きの総容量に対する割合です。
6. 設定は %LOCALAPPDATA%\DiskSpace\window.json に保存します。
   30秒ごと・ドライブの接続/取り外し時に更新します。手動更新も可能です。
   選択中のドライブが外されたら起動ドライブに戻ります。
7. ×は通知領域へ格納します。完全に終了するには「終了」を押します。

容量の意味
・保存に使える空き：GetDiskFreeSpaceExWのlpFreeBytesAvailableToCaller。
  今の利用者が使える容量です。Macの「重要なファイル用（推定）」とは別の指標です。
・総容量：同APIのlpTotalNumberOfBytes。クォータの影響を受ける場合があります。
・ディスク全体の空き：同APIのlpTotalNumberOfFreeBytes。
・内部はバイト単位。表示はWindowsと同じ1024進の単位で小数第2位まで表示します。
  1 GB = 1,073,741,824バイト（1024進）、小数第3位を四捨五入します。
  例：394,110,242,816バイトは367.04 GBです。小さい容量はMBなどで表示します。
  エクスプローラーは別の単位で表示する場合があるため、比較時はプロパティのバイト値を確認してください。
・0バイトは0.00 バイト、取得失敗は「取得できません」と表示します。
・マウント中の固定/リムーバブルドライブが対象。未挿入メディア・ネットワーク・光学ドライブ等は対象外。
  ドライブ文字のないフォルダマウントのみのボリュームは対象外です。

署名・起動
このアプリはコード署名していません。SmartScreenが警告する場合があります。
出所を確認したうえで実行を判断してください。組織のポリシーによっては起動できません。
管理者権限・自動起動登録・常駐サービスのインストールは不要です。

検証
GitHub ActionsのWindowsランナーで、変換テスト・実ドライブAPI・ウィンドウの生成/表示・
クリップボードの読み書き・配布exe起動のスモークテストを行います。
実ユーザー環境での画面操作、外付けドライブ接続/取り外し、SmartScreen経由の起動は別途確認が必要です。
